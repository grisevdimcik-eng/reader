# Читалка

Вставляешь ссылку на страницу или главу книги и читаешь чистый текст: без меню, рекламы и мусора. Тема, шрифт, размер и ширина колонки настраиваются, место чтения запоминается.

Ссылка вида `https://твой-адрес/?u=https://сайт.com/глава-1` открывает текст сразу.

## Страницы и главы

Если текст разбит на части, читалка ищет на странице ссылки «Далее» и «Назад» (по `rel=next/prev` и по тексту ссылки: «Далее», «Следующая», «Next», «»» и подобные). Если нашла, появляются кнопки внизу, стрелки ‹ › в верхней панели и клавиши ← →.

Не найдёт, если у сайта переход сделан номерами страниц без слов «далее/назад» или через JavaScript.

## Запуск на своём компьютере

    pip install -r requirements.txt
    uvicorn app:app --port 8080

Открой http://localhost:8080.

## Бесплатный хостинг без своего сервера

В папке есть `Dockerfile` и `render.yaml`, поэтому подойдёт любой хостинг, который запускает Docker-контейнеры.

Render (бесплатный тариф):
1. Залей папку в репозиторий на GitHub.
2. На render.com выбери New → Web Service (или Blueprint), укажи репозиторий.
3. Через пару минут получишь адрес вида `https://chitalka.onrender.com`.

Бесплатные тарифы обычно усыпляют сервис после простоя, и первое открытие после паузы занимает около минуты. Условия бесплатных тарифов меняются, проверь их на сайте хостинга.

Часть сайтов может не отдавать текст запросам с адресов хостингов. Если такой сайт не читается, на домашнем компьютере он, скорее всего, откроется.

## Проверка

    python3 tests/test_extract.py

Тест гоняет читалку по страницам с разной разметкой (заголовки в div, font, голый текст, абзацы через `<br><br>`, сноски, реклама посреди текста) и проверяет, что ничего не потерялось и мусор не попал в текст. Нашёл на реальном сайте проблему с версткой: добавь её сюда как новый случай.

## Ограничения

- Сайты, где текст подгружается JavaScript-ом, и сайты за логином читаются плохо или не читаются.
- PDF и файлы не поддерживаются, только веб-страницы.
- Адреса внутренней сети блокируются, чтобы через читалку нельзя было достучаться до сервера, на котором она стоит.
